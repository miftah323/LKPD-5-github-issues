Jawaban misi 1 
Memahami issues  
1. Apa fungsi GitHub Issue?
Untuk mencatat, mengacak, dan mengelola tugas, fitur baru, bug, atau ide proyek agar seluruh tim mengetahui apa yang sedang dikerjakan dan siapa penanggung jawabnya.


2. Mengapa pekerjaan sebaiknya dicatat sebagai Issue?
Agar ada transparansi kerja, alur pengerjaan terdokumentasi dengan baik, menghindari pengerjaan tugas ganda oleh dua orang berbeda, dan mempermudah pelacakan progress proyek.

  
3. Apa perbedaan Issue dengan Commit?
Issue: Rencana atau rekam jejak tugas/masalah yang perlu dikerjakan (perencanaan).  
Commit: Rekaman simpanan perubahan kode secara nyata yang dimasukkan ke dalam repository (eksekusi kode).
